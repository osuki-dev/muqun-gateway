# Muqun Desktop preview

## Changes and fixes

- **Unified Desktop Window System, 5-Tab Inspector, Session Tree & Compact Context**:
  - Unified window chrome across single-pane, split tiles, floating windows, and dockable drawers; removed legacy inline split panels and double headers; aligned single and split session menus.
  - Redesigned the Inspector into 5 focused tabs (`Queue | Git | Tree | Saved | Shells`) with real Git staging/commit/push/worktree actions, hierarchical **Session Tree** navigation, and one-click **Compact context**.
  - Enforced strict sidebar hiding for subagents across all views and added cycle detection plus automatic config self-healing (`sanitize_subagent_contexts`) so root Codex/subagent sessions never vanish from the sidebar.
- **Cross-platform macOS `WKWebView` plugin helper & Plugin UX overhaul**:
  - Added a native macOS offscreen `WKWebView` helper (`muqun-wry-embedded`) speaking the shared stdin/stdout JSON + RGBA frame protocol and bundled it in the signed macOS `.app` alongside Linux WebKitGTK.
  - Fixed plugin lifecycle, WebView/README precedence, panel error reporting, and `review-center` auto-run UX.
- **Terminal daemon DEC mode persistence (`?1049`/`?2048`), local shells on remote sessions, and shortcut fixes**:
  - `ScrollbackBuffer` in `term-daemon` now tracks active DEC private modes (`?1049` alt screen, `?2048` in-band resize for Neovim 0.10+, mouse reporting, bracketed paste, `DECCKM`) across 1 MiB ring eviction, cancels truncated trailing escapes (`CAN`) before restoring modes, reports exact raw `scrollback_len` framing on attach to eliminate timeout races, forwards accurate `TIOCSWINSZ` pixel dimensions, and fixes double-inset column calculation and Full-Screen Page resizing so long-running Neovim/TUI sessions never wrap diagonally after Desktop restarts or resizes.
  - Unified window header chrome across Split Tiles, Floating Windows, Right Drawer, Full-Screen Pages, Subagent Detail, Timeline Row Details, Terminal, and Image Viewer overlays (consistent leading icons, `header_button` `GhostMuted` + `Regular` sizing, bottom hairlines, and matching `[actions] → [...] → [surface] → [close]` ordering).
  - Added **+ Local** terminal creation when viewing remote sessions (with host badges on remote tabs), resolved the `Ctrl+Shift+T` shortcut collision (moved `Tasks` to `Mod+Alt+T` and made `TermNewTab` global), and flipped the `Queued` card deck stack so the widest front card sits closest to the composer.
- **Remote Fleet parity, gzip envelope decompression, Gateway self-update, and Theme/macOS polish**:
  - Enabled gzip compression on encrypted remote envelopes (`x-muqun-envelope-accept: gzip`) and skipped local filesystem media stats on remote hosts for snappy Tailscale/remote opens.
  - Added **Muqun Gateway** update checking and local non-interactive installation directly in `Settings → About`, plus live MCP tool schema inspection and JSON tool testing in `Settings → MCP Hub`.
  - Scoped composer/tile glow strictly to the active theme's accent hue (removing hardcoded rainbow/oklch/yellow colors across Desktop UI), restricted composer glow and sidebar highlight strictly to the focused split pane, eliminated white-hot rim blowout, and made idle `FOCUS_AURA`/`TILE_AURA` static so 4K Retina macOS windows rest at 0 FPS when idle instead of spinning Metal at 60–120 Hz.
  - Added clickable file chips beneath assistant messages for non-image workspace `image_assets` (including bare absolute workspace paths in prose and plain path-list fenced blocks) and routed `open_timeline_file` directly to the remote file viewer on remote sessions.
- **Unified MCP Hub Settings (`Settings → MCP Hub`)**: Displays Muqun Gateway's own built-in `/mcp` server card (live status, loopback endpoint URL, auto-injection state, active token count, built-in tools, and available skills) alongside external Streamable HTTP and stdio MCP servers (`mcp_hub_v1`). Supports adding, editing, enabling/disabling, live-probing, and removing external servers with access scope (`Local only` / `Local + tasks` / `All`), tool-level `Allowed tools` / `Blocked tools` wildcard ACLs, isolation (`Shared` / `Per session`), masked secret preservation, discovered tool previews, automatic state refresh when switching computers, and clear upgrade guidance on older Gateways.
- **App-style model picker, one-click queued send, and terminal reattach redraw**: Redesigned the Home and session model picker after Muqun App with a two-column provider rail (`Recently used` persisted per agent + catalog providers, automatically compacting to one column for single-provider agents), search across models and providers, an `All models` / `Free only` filter matching `Settings → Appearance → Corners`, context window & effort range captions (with `"none"` ordered before `"minimal"`), and inline effort chips directly under the selected model. Added a direct one-click `Send now` button to queued prompt chips (with upward-opening menus), and fixed terminal ``Ctrl + ` `` daemon reattachment to replay at the session's recorded dimensions and trigger a clean `SIGWINCH` TUI redraw.
- **Remote file preview & interactive remote terminal / `nvim`**: When viewing a remote computer's sessions, clicking files now opens them in Desktop's built-in viewer (text, diff, and images via Gateway's file-asset API) and supports opening files in a remote terminal (`nvim` / editor) over E2EE v2 `GET /api/pty/ws` (requires Gateway with `remote_pty_v1`).
- **Global window opacity, split-tile sidebar highlight, and session retention**: Added `Settings → Appearance → Window opacity` (`35%–100%` slider with Reset) applied uniformly across sidebar, panels, tiles, drawers, and terminal surfaces; split-view tiles keep all open sessions steadily highlighted in the sidebar without bouncing as the pointer moves across panes; closing a tile or refreshing sessions preserves active and recently closed sessions; and sidebar session filtering avoids redundant per-row lineage scans.
- **Model-led Multi-Agent Orchestration (MAO) in Desktop**: Configure a dynamic agent/model pool, per-session MAO overrides, automatic quota failover, optional `Auto code review` toggle (off by default for Lead-Model orchestration), and on-demand `Ask Advisor` directly from the composer and Settings.
- **Unified composer permission pill & queued image editing**: Permission modes and Auto-approve are consolidated into one labeled permission pill (`Ask` / `Auto-approve` / mode name) with one unified menu. Editing a queued message with image attachments preserves the real host upload path so thumbnails and re-sending work reliably.
- **Borderless animated GPU theme-aura focus & UI polish**: Replaced hard 1 px focus outlines across panels, split panes, composers, pills, and selectors with a borderless `rune-fx` animated theme-gradient aura that extracts vivid theme highlight stops (including light ink-primary themes such as `scene-voyager`). Fixed the Tasks computer-picker dropdown anchor so its menu opens directly beneath the trigger.
- **Single editor instance per workspace**: Opening multiple files from the same workspace reuses one editor tab/window (`nvim --listen` / `--server --remote-silent`, `vim --servername`, `hx`, `emacsclient`, and `--reuse-window` for VS Code/Cursor/etc.).
- **Synced Rune UI engine to `anomalyco/rune@46f334ef`**: Picks up 618 upstream fixes including native Wayland file drops (`#1808`/`#1866`/`#1872`), CJK `.ttc` fallback registration, >4 backdrop-blur slots (`#1800`), Wayland IME (`#1782`), and faster text shaping.
- Installed Desktop now checks its own release channel on startup and every six hours while running, and relaunches the verified package cleanly through Rune's normal quit hook. A notification opens the update page. You choose when to download and restart. To get this update from preview.27, open Settings → About.
- Search the model picker on Home and in sessions by model name, ID, or provider. Model and reasoning effort selections stay visible, including when working in split panes.
- The sidebar now uses the active theme's surface and artwork. On macOS the main workspace lets the desktop show through, and Reduce transparency restores an opaque background.
- Installing Bun or Herdr gives a newly downloaded binary time for its first startup. Herdr now downloads from its official release location.

## Compatibility and installation

Linux x86_64 packages target the Ubuntu 24.04 glibc 2.39 baseline. macOS packages target Apple Silicon. The Linux embedded browser needs WebKitGTK 4.1. The macOS archive contains a Developer ID signed, notarized and stapled application. Existing users can install the verified preview with:

```sh
curl -fsSL https://muqun.dev/desktop.sh | sh -s -- --channel preview
```

When updating from Settings, Desktop stays open until you choose to restart. Existing settings, pairing and conversations are retained. Installing the Desktop preview does not require a mobile App update. When you approve Gateway setup on a fresh computer, Desktop starts its built-in terminal in the background and connects Gateway to it. Existing tmux and Herdr installations remain supported, including Herdr protocol 17. Remote features depend on the paired Gateway and agent capabilities. A separately updated Gateway requires its own restart; active agent work should finish first.
