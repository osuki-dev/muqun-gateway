# Pull Requests & Issues

Choose **Refresh PRs & issues** to load the current workspace's GitHub repository.

Uses your existing `gh` authentication. This plugin only reads repository data; it does not create, comment on, merge or close anything.

Open pull requests and issues appear with author, status, labels and a link to details. The latest 30 of each are shown. Refresh is explicit, so opening a window does not start a network request.

Requires Bun and GitHub CLI (`gh`). For a repository on another forge, this version reports that it is unsupported.
